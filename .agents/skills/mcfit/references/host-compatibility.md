# 在不同 AI 助手中使用

McFit 是一组技能指令和确定性Python脚本，不依赖某个模型厂商的SDK、账号或聊天API。仓库中的`.agents/skills/mcfit`是默认存放位置，整个mcfit文件夹可单独复制、解压到宿主允许的目录。

## 能力要求

| 宿主能力 | 可用方式 |
|---|---|
| 读取SKILL.md、引用文件，执行Python，调用Streamable HTTP MCP | 完整编排工作流；实际业务功能仍受数据质量和当前实现范围限制 |
| 读取文件并执行Python，但没有MCP | 使用标明来源/时间的已有营养数据或合成演示，不声称完成实时查询 |
| 可以聊天/读文件，但不能执行Python | 解释需求并给用户CLI输入；由用户运行脚本后提供输出，不能凭空计算或声称已保存记录 |
| 仅能导入一份提示词，不能访问引用文件 | 不属于完整安装；请提供完整技能目录及执行通道，否则只做使用说明 |

宿主需要能够进行用户确认及访问本地私有存储；如代码运行于临时云沙箱，文件可能随会话消失，不承诺长期记录。身体资料不得为迁移方便而自动上传到云端。

## 导出与安装

在项目根目录执行：

```bash
python tools/export_skill.py --output dist/mcfit-skill.zip
```

压缩包包含`mcfit/SKILL.md`、`references/`及`scripts/`，使用固定清单打包，不带数据库、凭据、测试档案或开发缓存。输出存在时拒绝覆盖，请使用新的文件名。

若宿主支持导入Skill目录/压缩包，按其当前说明导入；不同产品的格式和目录未必一致，不能保证同一个ZIP被所有产品直接接受。不支持自动发现但能读本地文件的助手，可明确要求：“读取这个目录里的SKILL.md，按指令使用McFit。”确保它也能访问引用文件和脚本。

仓库用户可执行 `python mcfit.py --help`。单独导出后的技能使用 `python <技能目录>/scripts/cli.py --help`。两者使用相同代码、JSON输入和输出，支持从任意工作目录调用；私人数据目录通过MCFIT_DATA_DIR指定。

## MCP配置与调用

在实际执行AI工具的宿主中配置官方远程服务，详见[mcp-integration.md](mcp-integration.md)。Python不会自动调用任何助手的内部MCP API。工具名称可能带服务器前缀，按实际schema定位对应官方工具，不能只按名字相似就信任未知工具。

Token由宿主的凭据配置或进程环境注入，变量建议名为MCD_MCP_TOKEN；不让模型读取凭据值。只读白名单和订单授权要求对所有平台相同。若宿主不能配置工具白名单，仍必须遵循SKILL中的工具限制。

## 验证范围

已验证本地标准Python CLI，以及将导出技能放到仓库外目录后独立执行并获得相同输出。真实营养MCP调用在Codex宿主中完成过一次。这不等于已在所有AI产品中完成导入、权限、MCP和持久化联调；新宿主应先用合成输入测试，再做一次经授权的只读营养查询。
