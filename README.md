# McFit 🍔

## 项目介绍

想吃麦当劳，又想照顾一下自己的健身目标？把“这一顿怎么搭”交给 McFit 一起琢磨。

McFit 是一个可以交给不同 AI 助手使用的单餐搭配 Skill。告诉它你想增肌、减脂、维持体重，还是改善体态，再加上预算和口味偏好，就能一起比较这一餐的选择。

- **少一点纠结**：默认给出三套不同组合，想换饮料、去掉薯条，接着说就行。
- **看懂这一餐**：把热量、蛋白质等营养信息放在一起比较，不用自己逐项相加。
- **预算说清楚**：可以优先考虑营养、价格，或两者兼顾。查不到可靠价格时，会直接告诉你“这笔账暂时算不了”。
- **吃过再记账**：只有你确认实际吃了什么，才会记入记录，方便回看这一周、这个月已记录的营养和花费。

McFit 目前还在成长中：已能查询麦当劳官方营养信息，本地计算和记录功能可试用，把真实查询结果完整接入配餐的流程仍在完善。它是个人学习项目，非麦当劳官方产品；帮你参考一餐怎么选，不代下单，也不安排全天饮食。

## 安装方法

先准备好 **你常用的 AI 助手、Python 3.11 或以上版本，以及 Git**。助手需要能读取技能文件、运行本地脚本，并连接麦当劳 MCP 才能完成实时查询。不同平台的能力不同，纯聊天窗口不一定能直接运行。

**第一步：把 McFit 下载到电脑。** 在终端依次运行：

```bash
git clone https://github.com/Cooryn/McFit.git
cd McFit
python -m venv .venv
```

**第二步：把技能交给你的 AI 助手。** 完整技能位于 `.agents/skills/mcfit`，可复制到助手支持的技能目录，或让能读本地文件的助手读取其中的 `SKILL.md`。使用 Codex 时，可直接打开项目目录。

想带到另一个助手里？先导出一个干净的技能包：

```bash
python tools/export_skill.py --output dist/mcfit-skill.zip
```

按目标助手的方式导入或解压这个文件；各平台不一定都支持直接导入 ZIP。具体能力要求见 [跨助手使用说明](.agents/skills/mcfit/references/host-compatibility.md)。

**第三步：接上官方营养查询。** 前往 [麦当劳 MCP 开放平台](https://open.mcd.cn/mcp) 获取访问凭证，再按 [接入说明](.agents/skills/mcfit/references/mcp-integration.md) 完成配置。这里的 MCP 就是让助手查询官方信息的连接方式。凭证请自己保管，不要发到聊天或上传到仓库。

还没配置好？也可以先用演示数据看看效果。Windows PowerShell 运行：

```powershell
.\.venv\Scripts\python.exe mcfit.py smoke --input tests/fixtures/synthetic.json
```

Linux/macOS 将开头的 Python 路径换成 `.venv/bin/python` 即可。演示中的人物、餐品和价格都是测试数据，不是真实推荐。

## 使用示例

加载技能后，告诉助手“使用 McFit”，再说出你的想法即可。下面是自然语言示例，不是所有平台通用的快捷指令；若使用 Codex，也可以用 `$mcfit` 调用。

**先认识一下你：**

```text
使用 McFit，我25岁，175cm，65kg，想增肌。平时坐办公室，每周练三次力量，帮我建立档案。
```

**午饭有点选择困难：**

```text
使用 McFit，推荐一顿麦当劳午餐，650千卡以内，蛋白质至少30克。
```

**钱包和口味也要照顾到：**

```text
使用 McFit，这顿预算25元，不要薯条。查不到价格的话，先帮我看看营养怎么搭。
```

**看完方案，还想改一改：**

```text
使用 McFit，第二套换个饮料，其他要求不变。
使用 McFit，再来两套不一样的。
```

**回头看看自己记过什么：**

```text
使用 McFit，这个月我记录过的麦当劳，蛋白质一共多少？已知花费是多少？
```

首次建档时，McFit 会补问必要信息，等你核对后才保存。历史订单也要你同意才读取；买过不等于吃过，只有确认本人实际食用的部分才会记入统计。这里算的是你已记录的麦当劳，不是全天饮食总账。

## 目标用户

如果你有这些想法，McFit 也许能帮上忙：

- “正在健身，偶尔想吃麦当劳，希望这一餐选得更明白。”
- “我有预算，也有不想吃的东西，想少花点时间纠结搭配。”
- “想记下自己实际吃过什么，回头看看营养和花费。”
- “对 AI 小助手感兴趣，想试试官方信息查询能带来什么新玩法。”

常规营养估算面向一般健康成年人，只作参考。未成年人、妊娠或哺乳期、存在饮食障碍风险或需要疾病治疗饮食的人群，应寻求专业指导。有食物过敏时，也不要把信息缺失当作安全保证。
